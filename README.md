
# ❤️ Donate Bangladesh  

## 📌 Overview  
**Donate Bangladesh** is a platform dedicated to helping people in need by connecting donors with charitable causes. It aims to support underprivileged communities through financial aid, food distribution, education, and healthcare initiatives.

## ✨ Features  
- Secure donation system for financial aid  
- Support for food distribution, education, and healthcare initiatives  
- User-friendly interface for donors and beneficiaries  
- Integration with Stripe for seamless payment processing  
- Real-time data visualization using **Recharts**  
- Firebase authentication for secure user access  
- Notifications and alerts using **SweetAlert2** and **React Hot Toast**  

## ⚙️ Installation  
Follow these steps to set up the project locally:  

1. **Clone the Repository:**  
   ```sh
   git clone <repository-url>
   cd donate-bangladesh
   ```  
2. **Install Dependencies:**  
   ```sh
   npm install
   ```  
3. **Run the Development Server:**  
   ```sh
   npm start
   ```  

## 🚀 Usage  
- Visit `http://localhost:3000` to access the platform.  
- Register/Login to make a donation or request aid.  
- Browse different charitable causes and contribute securely via Stripe.  
- View impact reports and donation statistics.  

## 📦 Dependencies  
This project uses the following packages:  
- **UI & Styling:** `daisyui`, `react-icons`, `sweetalert2`, `react-spinners`  
- **State Management & API Calls:** `@tanstack/react-query`, `axios`  
- **Routing & Navigation:** `react-router-dom`  
- **Animation:** `lottie-react`  
- **Printing & SEO:** `react-to-print`, `react-helmet-async`  
- **Authentication & Backend:** `firebase`  
- **Payment Integration:** `@stripe/react-stripe-js`, `@stripe/stripe-js`  
- **Data Visualization:** `recharts`  

## 🔧 Configuration  
- Set up Firebase authentication and update the config in `.env`.  
- Configure Stripe API keys for secure transactions.
